# silent-hollow-kit



给自己省点事的小工具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/silent-hollow-kit.git
cd silent-hollow-kit
cargo build --release
```
